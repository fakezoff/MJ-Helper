# MJ Helper - помощник для госника

Указанные статьи **(/asu, /aticket, /agwarn)** могут различаться, их можно корректировать самостоятельно.

## Возможности и команды
- **/mj** - открывает главное меню скрипта
- **/asu ID** - открывает окно с выдачей умного розыска
- **/aticket ID** - открывает окно с выдачей умного штрафа
- **/agwarn ID** - открывает окно с выдачей умного спец. выговора
- **/log** - убирает информацию от скрипта из чата в консоль SampFuncs

### Новый вид /offer
![alt текст](https://i.imgur.com/E4UehlS.png)

Данный вид /offer дает возможность с помощью одной клавиши принимать или отклонять предложение, а также заранее увидеть, что именно тебе предлагают.
> Изменения клавиш доступны во вкладке "Настройки".
## Умный /wanted
#### С помощью команды /awanted вы можете не запариваться по поводу постоянных прописываний /wanted 1-7.
#### Подвинуть окошко можно с помощью кнопки "4" - окошко будет следовать за курсором, после чего повторно нажать "4" и оно останется на положенном месте. Также, можно убирать и включать курсор с помощью нажатии на колесико мышки.
![alt текст](https://i.imgur.com/t0hRnCa.jpeg)

### Вкладка "Департамент"
Возможность вызвать адвоката, прокурора и начальство одной кнопкой.
![alt текст](https://i.imgur.com/YmuZZwd.png)
После вызова, к примеру, адвоката, отправляется сообщение в чат департамента, а также в обычный о вызове адвоката и появляется таймер на ожидание адвоката.
![alt текст](https://i.imgur.com/6I4LM4d.jpeg)
После окончания таймера появляется соответствующее уведомление
![alt текст](https://i.imgur.com/kyRKiIl.jpeg)
> *Доступно редактирование отправляемого любого отправляемого текста.*
